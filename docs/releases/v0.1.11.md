## 更新与改进

- Claude Code 和 Codex 对话支持原生后续建议，按 Tab 填入输入框后可继续编辑。助手提问时会显示可选项，Codex 的额外权限申请可在审批卡中处理。
- Claude Code 可在原会话内切换权限，当前轮结束后按下一条消息所选的模式执行。窄窗口下，会话统计收进「会话详情」。

## 问题修复

- 改善 Windows 上 Claude Code 和 Codex 的 Python 中文输出，助手运行隔离模式时会收到使用 UTF-8 的执行指令。
- 聊天文件链接支持定位项目相对路径、绝对路径、用户目录和会话记录里的文件。
- 飞书应用被删除后停止自动重连，连接可直接编辑并重新绑定。
- 记忆提取遇到批次超时时可拆小重试，其他项目继续处理，运行记录会区分部分成功和全部失败。
