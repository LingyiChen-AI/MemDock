## 更新与改进

- Skill 管理按 Claude Code 和 Codex 的插件安装实例分组，支持折叠、搜索及查看包内 Skill。
- Skill 同步清单记录已安装的插件包，换设备后可以通过 Claude Code 或 Codex 恢复整包。
- Skill 管理可统一检查独立 Skill 和插件包，按需勾选后一键更新，并查看批量进度和结果。
- 应用每 30 分钟检查更新，有新版时在侧栏底部显示下载入口。
- 更新面板显示下载百分比和安装阶段，获取不到文件大小时显示持续下载动画。
- 设置新增开机自启开关，可选择在登录系统时启动 MemDock。
- 应用更新面板支持 Markdown，更新说明里的标题、列表和链接可以直接阅读。
- 发布说明新增面向用户的更新与修复摘要，并附上 GitHub 生成的 PR 和完整变更记录。
- 发布流程支持在打 tag 前预热三种平台的 Rust 构建缓存，减少发版时重复编译依赖。
